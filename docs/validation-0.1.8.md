## t 后缀缩略图重复计页

用户进一步确认：模糊图片的文件名末尾带 t，清晰原图不带 t。0.1.7 只识别 thumb / thumbnail / preview 等标记，没有覆盖该命名方式。本次用 20 张原图加 20 张 t 后缀缩略图复现，旧实现的相关回归测试失败，修复后只计 20 页。

- 新增 t / T 后缀配对，忽略扩展名差异；优先同逻辑路径，根级条目只有全包唯一对应原图时才回退匹配。
- 配对图片尺寸不大于原图，且像素尺寸更小或压缩条目更小时过滤；此种明确命名允许裁剪后的缩略图比例差异，也覆盖同尺寸的较低质量 JPEG。
- 原图名称本身以 t 结尾时仍可被匹配，避免 forestt → forest 失效；没有对应原图、不同章节无法配对或存在多个原图候选时保留。
- 缩略图目录和 t 后缀叠加时，旧进度沿多级别名恢复到最终原图。更新后重开漫画即可重建索引，无需重新导入，不修改原 ZIP。

## 长按拖动跟随放大

- 翻页模式补充直接处理长按后的 MOVE 事件；系统长按识别后不再依赖普通滑动回调。
- 翻页和连续模式都保存长按前的缩放与平移快照，按手指当前坐标在原画面中的对应点更新放大焦点；手指向右 / 向下移动会查看原画面右侧 / 下侧的内容。
- 松手或取消后恢复此前的缩放和位置，包含已经通过双指 / 双击放大的画面。
- 临时拖动不改写阅读位置，不滚动底层连续列表，也不触发翻页或打开菜单。

- 1 项原生 View 手势测试实际发送 DOWN / 长按 / MOVE / UP 事件，检查手指下像素从红区移到蓝区、绿区，再恢复原画面；临时查看不发布位置或误触菜单 / 翻页。

- 连续画布截图使用宿主 View 绘制，避免 Robolectric 的 PixelCopy 截图超时；未以截图接口失败作为产品行为依据。
