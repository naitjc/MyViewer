# MyViewer 0.3.1 验证记录

更新时间为 2026-11-13，北京时间。上一版记录见 [0.3.0](validation-0.3.0.md)。

## 指定文件夹下载

漫画与小说作品详情增加“下载到文件夹”，单章右侧增加文件夹按钮。调用系统 OpenDocumentTree 选择目标，保留可持久化的读写 URI 授权，下次定位上次选择的目录。导出无需先执行应用内离线下载。

漫画每章生成一个 ZIP，页面按五位数字顺序命名并使用实际图片格式扩展名，从右到左的作品带 ComicInfo 元数据。整部下载按章节先后顺序执行。小说整书按目录顺序生成 UTF-8 TXT，保留章名和段落，也可保存单章。批量操作选取当前目录内可读取的章节，并在界面显示可下载数量。

应用内临时文件完成后再写入系统文件夹，同名文件增加序号。写入失败或取消时尝试删除当前新建文件，并清理暂存文件。批量漫画保留已完成章节，状态提示保存数量。任务随应用进程运行，切换发现页后可看到共享状态，进程终止后需重新发起。目标文件夹保存的文件由用户通过文件管理器管理。

## 新增回归

- 文件提供器按照 Android DocumentsProvider 协议模拟系统文档存储，验证 ZIP / TXT 的真实文件写入。
- 漫画验证图片顺序、PNG / JPEG 扩展名、RTL 元数据、生成 ZIP 再由阅读器打开，以及后续章节失败时保留已完成 ZIP。
- 小说验证整书与单章内容、UTF-8 中文与 emoji、章节顺序、中途失败无残缺 TXT、重试及取消时的暂存清理。
- 验证同名自动编号、原文件保留、非法字符与长文件名处理、文件夹授权失效，以及写入异常和中断后的新文件清理。
- 实际 Aidoku WASM / Legado 源规则搭配原创响应，验证直接获取内容导出，并在删除源后从完整离线下载再次导出。
- 漫画与小说界面回归覆盖详情按钮、取消文件夹选择、返回选择结果、单章保存、选择期间 Activity 重建后的恢复、保存成功提示与输出文件。文件夹选择结果由测试模拟，手机系统文件管理器和外置存储尚未实测。

原生界面截图为 `.tooling/screenshots/comic-folder-download.png` 与 `novel-folder-download.png`。新增数据通过现有缓存和 URI 授权保存，数据库继续使用 schema 5。
