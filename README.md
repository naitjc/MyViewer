# MyViewer

Android TXT 小说 / ZIP 漫画及在线漫画阅读器。主要针对 iQOO Neo6 SE 使用，最低 Android 8.0（API 26）。

## 功能

- 封面书架，书名关键词搜索、小说 / 漫画筛选，按最近阅读、书名或导入时间排序，自动保存排序选择。
- 双击底部“书库”回到顶部；滚动到底后显示悬浮回顶按钮。设置中可选择每行 1～6 本，默认 3 本，自动保存。
- 系统文件选择器多选文件，或授权文件夹后扫描子目录。
- 每次导入选择直接读取原文件，或复制到应用保存独立副本。
- 小说提供目录、手动书签、分页 / 连续阅读、平移 / 仿真翻页设置。
- 字号、行距、纸色 / 浅色 / 护眼 / 深色背景、应用内亮度设置。
- 漫画提供逐页 / 连续阅读、左右阅读方向；双指在阅读画面内缩放，双击切换放大 / 还原，长按临时放大，拖动时放大画面与手指同向移动、松手恢复。
- 小说和漫画均支持自动阅读：定时翻页或匀速向下滚动，可设置翻页间隔 / 滚动速度，触摸画面暂停，后台暂停，末页再次前进后自动退出并标记已读完。
- 阅读历史和自动进度保存；清空历史、移出书架不删除书签或进度。
- 历史页显示今日、累计和每本书的阅读时长；阅读器前台亮屏时计时，手动与自动阅读都计入，后台 / 锁屏暂停。
- 单独清理漫画图片缓存，图片缓存上限 256 MB。

小说点击中部打开菜单，点击两侧或左右滑动翻页。漫画分页时点击两侧或左右滑动翻页，点击中部打开菜单；两侧翻页含义遵循从左到右 / 从右到左设置。图片放大后可拖动查看，两侧轻点仍可翻页，拖动不会触发翻页。本地阅读及已完整下载的在线章节可离线使用。

## 0.2.2 末页自动完成与源兼容修复

- TXT、ZIP 与在线章节在末页继续向后翻时自动退出并标记已读完；连续阅读需到达底部后再向上划一次。自动阅读在末尾再次前进时执行相同行为。
- 进入末页或把进度拖到末尾后仍可继续查看。书架长按已完成书籍可取消完成标记，继续阅读卡片会再次显示该书。
- 在线漫画读完一章后返回章节列表并标记该章，当前已知章节全部完成后自动标记整部作品。
- “发现”的已安装源右侧增加卸载按钮，确认后删除源程序，可重新安装。已下载章节继续支持离线阅读。
- 修正禁漫天堂 v3 页面上下文解码错位导致的“漫画源布尔编码无效”，补齐该源所需的 Canvas 图片分块重组。
- 设置各分组初始全部折叠，包括书架每行书籍数量；本次使用中可独立展开、收起。

## 0.2.1 多语言筛选与完成状态存储

- “发现”提供英语、日语、韩语等常用筛选，以及“更多语言”菜单；选项由仓库索引生成。地区和文字变体按基础语言合并，简繁体中文统一归入“中文”。
- 语言筛选会在进入源、打开源设置并返回后继续保留；筛选也覆盖多语言源。
- 数据库升级至 schema 4，为书籍和章节新增完成状态字段，0.2.2 继续使用该结构并保留已有标记。

## 0.2.0 在线漫画源

- 底部新增“发现”，默认加载 Aidoku Community Sources 索引，支持修改 HTTPS 仓库地址、搜索源、中文筛选、安装和手动更新。
- Android 内置 Chicory WASM 解释器，直接执行 Aidoku `.aix` 中的源程序，提供网络、HTML、设置存储和基础 JavaScript 接口。
- 已安装源支持漫画搜索与分页、作品详情、章节目录、加入书架和手动刷新章节。源设置可调整站点地址、语言及静态开关 / 选项。
- 在线章节复用既有漫画阅读器，支持翻页、连续阅读、缩放、自动阅读、章节切换及作品级阅读时长；每章独立保存进度。
- 章节可逐章下载、取消、重试或删除。完整下载存入应用文件目录，退出后仍可离线阅读；下载任务随应用进程运行，取消后再次下载可复用相同页面列表下的已完成文件。
- 在线图片与封面临时缓存合计上限 256 MB，设置中的“清理漫画图片缓存”可清理在线页面缓存。主动下载的章节可从作品详情单独删除。
- 数据库升级至 schema 3，提供 schema 1 → 2 → 3 的迁移，保留既有书籍、书签、偏好和阅读时长。

### 使用

进入“发现”，安装所需源，再点击源名称搜索漫画。作品详情可加入书架、打开章节或点击下载按钮。书架中的在线漫画会打开章节详情，已下载章节可以离线读取。在“漫画源设置”中调整参数后，重新搜索或刷新章节即可应用。

### 源兼容范围

当前支持新式 Aidoku 的搜索、详情、章节和 URL 图片页面协议。2026-11-11 已对 Guya v2、拷贝漫画 v24 实测网络调用，并对拷贝漫画页面执行原生图片解码。站点后续可用性取决于网站和源更新。

0.2.2 另对禁漫天堂 v3 验证实际源程序的页面解码与生成图片的分块重组，并完成在线搜索与作品详情调用。Canvas 目前覆盖图片复制、缩放和旋转操作。

浏览器 WebView 验证、登录交互、Canvas 路径 / 文字绘制、文本 / 内嵌图片 / ZIP 页面、动态筛选与首页编排仍待接入，相关源调用会显示错误或提供基础搜索功能。其余源需要逐个验证。设备最低版本仍为 Android 8.0，当前验证使用 JVM / Robolectric，目标手机体验待实测。

## 0.1.10 阅读时长统计

- 历史页新增今日阅读 / 累计阅读卡片，各本书显示累计时长；清空历史后继续保留统计。
- 阅读器在前台、屏幕点亮且未锁定时计时，手动阅读和自动阅读都计入；后台、锁屏和退出暂停，跨午夜分别记录到两天。
- 使用单调时钟测量时长，分段保存累计检查点，重复保存不会重复累计。异常终止时可能丢失最后约 5 秒尚未保存的时间。
- 统计从本次更新后的阅读开始，无法补算旧时长；数据库提供保留旧书库、进度、书签和设置的升级迁移。

## 0.1.9 长按拖动方向与自动阅读

- 长按放大的拖动方向反转：手指向右 / 向下拖，放大画面向右 / 向下移动；起始放大位置不跳变，松手或取消后恢复此前画面。
- 点击阅读画面中部，再点击播放图标进入“自动阅读”：翻页模式可设置 2～60 秒／页，连续模式可设置 1～10 档滚动速度。
- 小说和漫画均可使用；速度设置保存在本机，触摸画面或点击“暂停自动阅读”即可暂停，切到后台、退出阅读或读到末尾时停止。
- 自动阅读从当前进度开始，重开书籍后由用户再次启动；漫画等待当前图片加载后再计时或滚动，暂停 / 结束时补存最后位置。

## 0.1.8 漫画 t 后缀缩略图与跟手放大

- 补充识别文件名末尾的 `t` / `T` 缩略图，例如 `001t.jpg` 对应 `001.jpg`，保留原图并更新总页数；支持裁剪缩略图和同尺寸的较小压缩版本。
- 仅在找到唯一对应原图、尺寸不大于原图且像素尺寸或文件体积更小时过滤，保留无法配对的图片；旧进度可从 `t` 条目恢复到原图。
- 翻页和连续阅读均支持长按后拖动手指改变放大查看的位置；手指移到哪里就查看原画面的哪里，松手 / 取消后恢复此前的缩放和位置。

## 0.1.7 漫画缩略图重复页修复

- ZIP 内带有 `thumb`、`thumbnail`、`preview` 等目录或文件名标记的图片，有唯一对应原图且尺寸 / 比例符合时，只将原图计为漫画页。
- 保留没有对应原图的缩略图、无法确定对应关系的图片和普通小图；不会按图片大小或画面内容对整本漫画去重。
- 之前保存到缩略图的阅读位置会映射到对应原图，逐页和连续模式使用相同的有效页面列表。

## 安装与构建

已构建的安装包见 [GitHub Releases](https://github.com/naitjc/MyViewer/releases/latest)。源码仓库不保存签名密钥、本机配置与构建缓存。

最终签名体验包输出位置：`dist/MyViewer-0.2.2.apk`。转到手机上覆盖安装即可；签名脚本按 Gradle 的实际版本名输出文件。

Android Studio 可直接打开本项目。命令行需要 JDK 17 或以上、Android SDK 36 与 Build Tools 36.0.0：

```sh
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest :app:lintDebug
```

本机可使用封装脚本，它会选择已安装的 JDK 和 SDK，将构建缓存写入本项目的 `.tooling/`：

```sh
./scripts/build.sh :app:assembleDebug
./scripts/build.sh :app:testDebugUnitTest :app:lintDebug
./scripts/sign-release.sh
```

签名脚本首次运行时在 `.signing/` 创建应用专用签名材料；此目录已被 Git 忽略，也不作为构建缓存。保留它即可继续签署后续覆盖更新版本。后续版本同时递增 `app/build.gradle.kts` 中的 versionCode。

Debug 和最终签名包使用不同签名；首次手机试用以 `dist/` 中的签名包为准。

## 测试资料

`sample-books/` 是用本项目脚本生成的原创小样例，包含 UTF-8 / GB18030 小说、分页漫画和长条漫画。可把整个目录传到手机，通过文件夹扫描体验两种内容。

```sh
python3 scripts/make-samples.py
```

分页 ZIP 的文件写入顺序刻意为 1、10、2、3，用于检查阅读器是否按 1、2、3、10 显示；其中元数据标记从右到左。长条 ZIP 用于检查连续模式与页内位置恢复。

自动测试覆盖文本编码与章节位置、数字排序、分页边界、字号变化后的文字锚点、数据库进度隔离、复制与重复导入、ZIP 元数据及核心页面流程。另有 48 页长条漫画、慢解码预览兜底、重复绑定、异步释放、双向模式切换、加载时翻页、双指原地缩放和长按恢复检查；20 张原图加 20 张缩略图用例检查页数、原图保留、旧位置映射和两种导入方式。验证结果见 `VALIDATION.md`；页面截图位于 `.tooling/screenshots/`，真机帧率与触感仍需复测。

## 首版兼容范围

- 漫画：普通无密码 ZIP，内部 JPG / JPEG / PNG / WebP；没有递归打开嵌套 ZIP。
- TXT：UTF-8、UTF-16 BOM、GB18030 自动识别，阅读设置中可手选编码；上限 48 MB 原文件、约 2400 万 UTF-16 单元。
- 直接读取的原文件移动或授权失效后，需要重新定位；无法随机读取的 ZIP 来源需要使用复制导入。
- 本地索引与封面按文件内容生成；在线漫画元数据来自已安装源。当前没有 EPUB、RAR 或手动备份界面。
- 替换原文件内容后，旧位置按原偏移尝试恢复，暂未实现跨版本内容的语义匹配。

需求记录见 [PROJECT_DESIGN.md](PROJECT_DESIGN.md)，工程设计建议见 [TECHNICAL_DESIGN.md](TECHNICAL_DESIGN.md)。工程实际行为和本文件中的兼容范围优先于尚未验证的设计建议。
